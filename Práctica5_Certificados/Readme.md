# Práctica: Certificados Digitales con XCA

Este repositorio contiene el desarrollo completo de la práctica sobre certificados digitales usando la herramienta **XCA**, en el contexto de la asignatura *Seguridad en la Información*.

## 📋 Contenido de la práctica

### 🧩 Ejercicio 1: Certificados con XCA

- Creación de base de datos en XCA
- Generación de certificados:
  - Rol CA: certificado autofirmado
  - Rol Usuario: creación de CSR
  - Firma del CSR por la CA
- Revocación:
  - Solicitud de revocación del usuario
  - Generación y exportación de CRL

## 🛠 Herramientas utilizadas

- [XCA](https://www.hohnstaedt.de/xca/)

## 🧑‍🏫 Requisitos

- Certificados en formato `.crt`, `.pem`
